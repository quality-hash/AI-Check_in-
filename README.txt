เว็บเช็คชื่อคลาส Claude AI - ไฟล์สำหรับขึ้นเซิร์ฟเวอร์เอง
=======================================================

ไฟล์ในชุดนี้
  index.html          หน้าเว็บเช็คชื่อ (เปิดได้เลย)
  xlsx.full.min.js    ตัวอ่านไฟล์ Excel/CSV (วางไว้โฟลเดอร์เดียวกับ index.html)
  Code.gs             โค้ด Google Apps Script สำหรับบันทึกลง Google Sheets
  students.csv        รายชื่อผู้เรียน 25 คนปัจจุบัน ใช้นำเข้าผ่านปุ่ม "นำเข้า CSV / Excel"

1) ขึ้นเซิร์ฟเวอร์
   อัปโหลด index.html และ xlsx.full.min.js ไว้ในโฟลเดอร์เดียวกัน
   (ใช้ได้กับโฮสต์ static ทั่วไป เช่น Apache, Nginx, GitHub Pages, Netlify)

2) เชื่อม Google Sheets
   ก. สร้าง Google Sheet ใหม่ > เมนู ส่วนขยาย > Apps Script
   ข. ลบโค้ดเดิม วางเนื้อหาจาก Code.gs แล้วกดบันทึก
   ค. กด ทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่ > ประเภท: เว็บแอป
        เรียกใช้ในฐานะ: ฉัน
        ผู้มีสิทธิ์เข้าถึง: ทุกคน (Anyone)
      กดอนุญาตสิทธิ์ แล้วคัดลอก URL ที่ลงท้ายด้วย /exec
   ง. เปิด index.html หา CONFIG ด้านบนของ <script> แล้วใส่
        googleScriptUrl: "https://script.google.com/macros/s/xxxx/exec",
   จ. อัปโหลด index.html ใหม่ แล้วเปิดเว็บ กด "นำเข้า CSV / Excel" เลือก students.csv

   ชีต Students / Checkins / Settings จะถูกสร้างให้อัตโนมัติ
   ชีต Checkins มี วันที่, ชื่อ, บริษัท, เวลาเข้าเรียน, สถานะ (มาเรียน/สาย), สายกี่นาที และลายเซ็น
   หน้าเว็บดึงข้อมูลใหม่จากชีตทุก 15 วินาที (แก้ได้ที่ refreshSeconds)
   ถ้าแก้ Code.gs ภายหลัง ต้อง Deploy เวอร์ชันใหม่ (จัดการการทำให้ใช้งานได้ > แก้ไข > เวอร์ชันใหม่)

3) ซ่อนปุ่มจัดการจากผู้เรียน (ไม่บังคับ)
   ใส่ adminKey: "รหัสของคุณ" ใน CONFIG
   ผู้เรียนเปิด https://เว็บของคุณ/ จะเห็นแค่ปุ่มลงชื่อ
   ผู้สอนเปิด https://เว็บของคุณ/?admin=รหัสของคุณ เพื่อนำเข้า/เพิ่ม/ลบ/ตั้งค่า
   หมายเหตุ: เป็นการซ่อนปุ่มเท่านั้น ผู้ที่รู้ลิงก์ Apps Script ยังเขียนข้อมูลได้

ถ้ายังไม่ใส่ googleScriptUrl เว็บจะเก็บข้อมูลในเบราว์เซอร์เครื่องนั้นเท่านั้น
(เหมาะกับใช้แท็บเล็ตเครื่องเดียวหน้าห้อง แล้วกด "ดาวน์โหลด CSV" ตอนจบคลาส)
